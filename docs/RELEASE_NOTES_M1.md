# Release notes — M1 platform foundation

This milestone converts the autonomous-discovery v1 scaffold into a governed full-stack platform foundation. The principal changes are the fixed survey taxonomy with executable evidence semantics, candidate/human-label data workflow, capability registry, local leakage-aware retrieval, immutable approvals, retry scheduling, and encrypted zero-day case storage.

No claim is made that M2 active 0day discovery or M3 adaptive remediation/Rust-Shyper integration is complete.
